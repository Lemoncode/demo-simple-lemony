# Personas — Villa Azahar

Quiénes usan la web y qué condiciona el diseño. Fichero del proyecto: amplíalo cuando
aparezcan perfiles nuevos (por ejemplo, el gestor que recibe las solicitudes).

## Huéspedes: familias y grupos de amigos

- **Quiénes son**: familias y grupos de amigos que buscan unas vacaciones tranquilas junto
  al mar (hasta 8 huéspedes).
- **Contexto y dispositivo**: casi siempre llegan **desde el móvil**, por un enlace
  compartido o una red social. Comparan con calma, pero deciden rápido.
- **Experiencia**: usuarios generales. No dominan la web ni conocen la casa.
- **Frecuencia**: ocasional. Unas pocas visitas antes de reservar.
- **Qué les decide**: las fotos y unos pocos datos clave (habitaciones, baños, huéspedes,
  acceso al mar).
- **Qué quieren hacer**: llegar rápido a las fechas disponibles o al contacto.
- **Implicación para el diseño**: **móvil primero**. Cuando haya que elegir una jerarquía,
  se decide para 390 px. El tono es cercano y de tú, y las fotos son las protagonistas.
